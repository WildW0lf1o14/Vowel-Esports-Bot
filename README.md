discord bot for use within the Vowel esports org for roster related presentation and general server uses, with patches needed to get to full serviceability.

bot.py is the main bots source code, bot.test is code to test if its working and there is a backup of the bots code as needed.

config.py is currently work in progress but will be used to help configure features of the bot/ manage runtimes

database.py is the backend file used to store the roster and player data, will soon have a file to determine permissions for admins, managers, captains and general members.

requirements.txt is basically a operational guide that is currently incomplete (like the bot) so its currently just contains the code for the discord api
